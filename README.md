# 📚 Registro de Libros en JavaScript

Mini proyecto desarrollado en JavaScript para practicar los fundamentos de la **Programación Orientada a Objetos (POO)**.

## 📌 Descripción

El programa permite registrar una cantidad de libros indicada por el usuario, solicitando la siguiente información:

- Título del libro.
- Autor.
- Año de publicación.
- Estado (disponible o prestado).

Cada libro se crea como una instancia de la clase `Libro` y se almacena en un arreglo.

## 🚀 Tecnologías

- JavaScript
- HTML
